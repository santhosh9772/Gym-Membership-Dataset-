 # 🏋️ Gym Membership Analysis Dashboard 
 
📌 Project Overview

  This project analyzes gym membership data using Microsoft Excel to understand member behavior, gym attendance, subscription types, group lesson participation, and personal training preferences.
The project includes data cleaning, Excel formulas, Pivot Tables, charts, KPI analysis, and an interactive dashboard.

 🎯 Project Objectives
Analyze total gym members.
Compare Premium and Standard subscriptions.
Understand gym visit frequency.
Identify the most commonly visited days of the week.
Analyze average time spent in the gym.
Understand group lesson participation and preferences.
Analyze personal training participation.
Create an interactive Excel dashboard.
Generate useful business insights.

🧹 Data Cleaning

The following data preparation activities were included:

Reviewed the dataset for missing values.
Checked duplicate records.
Organized column names and data formats.
Created age groups for member segmentation.
Prepared day-wise visit indicators for Sunday through Saturday.
Organized data for Pivot Table analysis.
Prepared the dataset for dashboard reporting.


  📈 Key Performance Indicators (KPIs)

  The dashboard focuses on the following metrics:

Total Members
Average Time Spent in the Gym
Average Visits Per Week
Premium Members
Standard Members
